## A place for your ideas

Write your posts in Markdown. Headings, links, lists, images and code blocks are supported, and the homepage picks up each published entry automatically.

```html
<pre><code>const hello = 'world';</code></pre>
```

Code blocks use syntax highlighting that follows the system’s light or dark color scheme.

## Writing your next post

1. Create a Markdown file in `src/content/blog/`.
2. Add a title, description and date to the frontmatter.
3. Write your article below the frontmatter.
4. Run the build and deploy the generated site.

Set `draft: true` while you are working on a post. Drafts are excluded from the homepage, article pages and RSS feed.
